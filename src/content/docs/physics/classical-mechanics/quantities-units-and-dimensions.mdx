## 物理量と単位

物理学は、自然の現象を測り、測った量の間の関係を式で書く。測った結果を数で書くには、何を基準に測ったかの約束が要る。本章は、測定値の書き方の約束と、式を確かめる方法を扱う。

### 物理量の書き方

測定で大きさを数値として表せる量を**物理量**と呼ぶ。長さ・時間・質量は物理量である。

物理量の大きさは、基準の量の何倍かで表す。基準の量を**単位**と呼ぶ。物理量は数値と単位の積である。

$$
\text{物理量} = \text{数値} \times \text{単位}
$$

例えば、長さ $l$ がメートルの 3 倍のとき、次のように書く。

$$
l = 3\ \mathrm{m}
$$

本章は次の書き方に従う。

- 量を表す文字は斜体で書く。例: 長さ $l$、質量 $m$
- 単位の記号は立体で書く。例: メートル $\mathrm{m}$、秒 $\mathrm{s}$
- 数値と単位の記号の間に空白を置く。

斜体と立体の区別により、質量 $m$ とメートル $\mathrm{m}$ を見分ける。

同じ物理量は別の単位でも書ける。$\mathrm{cm}$ はセンチメートルで、$1\ \mathrm{m} = 100\ \mathrm{cm}$ である。

$$
l = 3\ \mathrm{m} = 300\ \mathrm{cm}
$$

単位を小さくすると数値は大きくなる。数値と単位の積である物理量は変わらない。

### 単位の積と商

単位は文字と同じように掛け算と割り算ができる。例えば、$6\ \mathrm{m}$ 進むのに $2\ \mathrm{s}$ かかったとき、距離を時間で割ると次の量になる。

$$
\frac{6\ \mathrm{m}}{2\ \mathrm{s}} = 3\ \frac{\mathrm{m}}{\mathrm{s}} = 3\ \mathrm{m/s}
$$

単位の積と商は次のように書く。

- 商: 斜線 $/$ で書く。$\mathrm{m/s}$ は「メートル毎秒」と読む。
- 負の指数: [指数法則](../../../math/algebra/laws-of-exponents/)により、$\mathrm{m/s}$ は $\mathrm{m\,s^{-1}}$ とも書ける。
- 積: $\mathrm{kg\,m}$ のように、単位の記号の間に小さな空白を置く。

## SI 基本単位

世界で共通に使う単位の体系を**国際単位系**と呼び、**SI** と略す[^si-name]。SI は 7 つの量を基本に選ぶ。選んだ量を**基本量**と呼び、基本量の単位を**基本単位**と呼ぶ。

| 基本量     | 単位の名前 | 単位の記号     |
| ---------- | ---------- | -------------- |
| 時間       | 秒         | $\mathrm{s}$   |
| 長さ       | メートル   | $\mathrm{m}$   |
| 質量       | キログラム | $\mathrm{kg}$  |
| 電流       | アンペア   | $\mathrm{A}$   |
| 熱力学温度 | ケルビン   | $\mathrm{K}$   |
| 物質量     | モル       | $\mathrm{mol}$ |
| 光度       | カンデラ   | $\mathrm{cd}$  |

基本量の選び方は約束である。SI の他の単位は、7 つの基本単位の積と商で表せる。

SI は 7 つの定数の値を固定して、基本単位を定める。例えば、光が真空（物質の無い空間）を $1\ \mathrm{s}$ の間に進む距離を、ちょうど $299\,792\,458\ \mathrm{m}$ と定める。数字の間の小さな空白は 3 桁ごとの区切りである。$1\ \mathrm{m}$ は、光が真空を $1/299\,792\,458\ \mathrm{s}$ の間に進む距離である。

本章の計算で使う基本単位は $\mathrm{s}$・$\mathrm{m}$・$\mathrm{kg}$ の 3 つである。残りの 4 つは本章の計算に現れない。

## 組立単位

基本単位の積と商で作る単位を**組立単位**と呼ぶ。面積の単位 $\mathrm{m^2}$ は組立単位である。

本章は、運動に関する 2 つの量を次の素朴な意味で使う。

- **速さ**: 移動した距離を、かかった時間で割った量である。単位は $\mathrm{m/s}$ である。
- **加速度**: 速さの変化を、かかった時間で割った量である。単位は $\mathrm{m/s}$ を $\mathrm{s}$ で割った $\mathrm{m/s^2}$ である。読み方は「メートル毎秒」の後に「毎秒」を続ける。

よく使う組立単位には、固有の名前と記号が付いている。次の表は 5 つを示す。表の右端の列は SI の定義であり、本章は定義として認める。

| 量         | 単位の名前 | 記号          | 単位の大きさ                                                                          | 基本単位での表し方            |
| ---------- | ---------- | ------------- | ------------------------------------------------------------------------------------- | ----------------------------- |
| 周波数     | ヘルツ     | $\mathrm{Hz}$ | $1\ \mathrm{s}$ に $1$ 回の繰り返し                                                   | $\mathrm{s^{-1}}$             |
| 力         | ニュートン | $\mathrm{N}$  | 他の力が無いとき、質量 $1\ \mathrm{kg}$ の物体に加速度 $1\ \mathrm{m/s^2}$ を与える力 | $\mathrm{kg\,m\,s^{-2}}$      |
| 圧力       | パスカル   | $\mathrm{Pa}$ | 面積 $1\ \mathrm{m^2}$ あたり $1\ \mathrm{N}$ の力                                    | $\mathrm{kg\,m^{-1}\,s^{-2}}$ |
| エネルギー | ジュール   | $\mathrm{J}$  | $1\ \mathrm{N}$ の力が物体を力の向きに $1\ \mathrm{m}$ 動かすときに移るエネルギー     | $\mathrm{kg\,m^2\,s^{-2}}$    |
| 仕事率     | ワット     | $\mathrm{W}$  | $1\ \mathrm{s}$ あたり $1\ \mathrm{J}$ のエネルギーの移動                             | $\mathrm{kg\,m^2\,s^{-3}}$    |

例えばジュールは $\mathrm{N\,m}$ とも書ける。指数法則で基本単位に直すと、表の値になる。

$$
\mathrm{J} = \mathrm{N\,m} = (\mathrm{kg\,m\,s^{-2}})\,\mathrm{m} = \mathrm{kg\,m^2\,s^{-2}}
$$

等号の右辺に係数は現れない。基本単位の積と商に係数 $1$ で結び付く性質を**一貫性**と呼ぶ。本節の組立単位は一貫性を持つ。

## 接頭語と単位の換算

### 接頭語の表

物理で扱う量の大きさの幅は広い。大きい数や小さい数を短く書くため、単位の記号の前に $10$ の累乗を表す文字を付ける。文字を**接頭語**と呼ぶ。例えば、$\mathrm{k}$ は $10^3$ を表すので、$1\ \mathrm{km} = 10^3\ \mathrm{m}$ である。

SI の接頭語は全部で 24 個あり、$10^{-30}$ から $10^{30}$ までを覆う。次の表は、よく使う 12 個を示す。

| 倍率       | 名前     | 記号         |
| ---------- | -------- | ------------ |
| $10^{12}$  | テラ     | $\mathrm{T}$ |
| $10^{9}$   | ギガ     | $\mathrm{G}$ |
| $10^{6}$   | メガ     | $\mathrm{M}$ |
| $10^{3}$   | キロ     | $\mathrm{k}$ |
| $10^{2}$   | ヘクト   | $\mathrm{h}$ |
| $10^{-1}$  | デシ     | $\mathrm{d}$ |
| $10^{-2}$  | センチ   | $\mathrm{c}$ |
| $10^{-3}$  | ミリ     | $\mathrm{m}$ |
| $10^{-6}$  | マイクロ | μ            |
| $10^{-9}$  | ナノ     | $\mathrm{n}$ |
| $10^{-12}$ | ピコ     | $\mathrm{p}$ |
| $10^{-15}$ | フェムト | $\mathrm{f}$ |

### 接頭語の規則

接頭語の使い方には 3 つの規則がある。

- **接頭語は単位の記号と一体である。** 累乗は接頭語ごとかかる。例えば $\mathrm{km^2}$ は $(\mathrm{km})^2$ を表すので、$1\ \mathrm{km^2} = (10^3\ \mathrm{m})^2 = 10^6\ \mathrm{m^2}$ である。
- **接頭語は 1 つだけ付ける。** 例えば $10^{-9}\ \mathrm{m}$ は、ミリとマイクロを重ねず、$1\ \mathrm{nm}$ と書く。
- **質量の接頭語はグラムに付ける。** 基本単位 $\mathrm{kg}$ が接頭語 $\mathrm{k}$ を含むためである[^kg]。グラムの記号は $\mathrm{g}$ で、$1\ \mathrm{g} = 10^{-3}\ \mathrm{kg}$ である。例えば $10^{-6}\ \mathrm{kg}$ は $1\ \mathrm{mg}$ と書く。

### 単位の換算

単位の換算は、単位を等しい量で置き換える操作である。例えば、時間の単位の時 $\mathrm{h}$ は $1\ \mathrm{h} = 3600\ \mathrm{s}$ で定まる。時 $\mathrm{h}$ は SI の単位ではなく、接頭語のヘクトとも別のものである。

キロメートル毎時 $\mathrm{km/h}$ を $\mathrm{m/s}$ に直すには、$\mathrm{km}$ と $\mathrm{h}$ を次のように置き換える。

$$
36\ \mathrm{km/h} = 36 \times \frac{10^3\ \mathrm{m}}{3600\ \mathrm{s}} = 10\ \mathrm{m/s}
$$

$\mathrm{km}$ や $\mathrm{km/h}$ は係数 $1$ で基本単位に結び付かないので、一貫性を持たない。一貫性の無い単位のまま計算すると、式に換算の係数が入る。式に値を代入する前に、量を基本単位と組立単位にそろえる。

## 次元

### 次元の定義

単位は測り方の約束である。長さを $\mathrm{m}$ で測っても $\mathrm{km}$ で測っても、長さであることは変わらない。量の基本量への依存の仕方を、単位の選び方と無関係に表したものを**次元**と呼ぶ。

本章で使う基本量の次元を次の記号で表す。SI の文書が使う正式な記号で、飾りのない立体の大文字で書く。単位の記号や接頭語の $\mathrm{M}$（メガ）・$\mathrm{T}$（テラ）とは別のものである。

| 基本量 | 基本単位      | 次元の記号   | 読み方 |
| ------ | ------------- | ------------ | ------ |
| 長さ   | $\mathrm{m}$  | $\mathsf{L}$ | エル   |
| 質量   | $\mathrm{kg}$ | $\mathsf{M}$ | エム   |
| 時間   | $\mathrm{s}$  | $\mathsf{T}$ | ティー |

物理量 $Q$ の単位を基本単位で表し、表の対応で次元の記号に置き換えた式を、$Q$ の次元とする。$Q$ の次元を $[Q]$ と書き、「$Q$ の次元」と読む。角括弧は広く使う便宜的な書き方である[^bracket]。

本章で扱う量の次元は次の形になる。指数 $a$・$b$・$c$ は有理数である。

$$
[Q] = \mathsf{L}^a\mathsf{M}^b\mathsf{T}^c
$$

例えば、力 $F$ の単位は $\mathrm{N} = \mathrm{kg\,m\,s^{-2}}$ である。力の次元は $[F] = \mathsf{L}\mathsf{M}\mathsf{T}^{-2}$ である。

### 次元の計算

量 $A$・$B$ について、次の規則が成り立つ。3 つ目の規則の $p$ は有理数で、$A$ は正の量とする。

$$
[AB] = [A][B], \qquad \left[\frac{A}{B}\right] = \frac{[A]}{[B]}, \qquad [A^p] = [A]^p
$$

規則の理由は、単位の積と商が指数法則に従うことである。累乗根を含む単位も、文字と同じように扱う。$\mathsf{L}$ などの記号は数ではない。指数の計算は、[累乗根と有理数指数](../../../math/algebra/radicals-and-rational-exponents/)の指数法則と同じ形で進める。

$\mathsf{L}$・$\mathsf{M}$・$\mathsf{T}$ の指数がすべて $0$ の量を**無次元量**と呼ぶ。無次元量の次元を $1$ と書く。数は無次元量である。同じ次元の 2 つの量の比も無次元量である。例えば、2 つの長さの比の次元は $\mathsf{L}/\mathsf{L} = 1$ である。

### 次元の一致

2 つの次元が等しいとは、$\mathsf{L}$・$\mathsf{M}$・$\mathsf{T}$ の指数がそれぞれ等しいことである。次の原理を認める。

> **次元の一致（承認事項）.** 物理量を結ぶ正しい等式では、両辺の次元が等しい。和と差では、各項の次元が等しい。

根拠は、物理量の間の関係が人の決めた単位に依らないことである[^numeric]。単位の大きさの取り方は約束である。SI が $\mathrm{m}$ を秒から定めるのも約束の 1 つである。$k$ を $1$ より大きい数とし、長さの単位だけを $1/k$ 倍に取り直す。次元が $\mathsf{L}^a\mathsf{M}^b\mathsf{T}^c$ の量の数値は $k^a$ 倍になり、$b$ と $c$ は倍率に効かない。例えば $\mathrm{m}$ から $\mathrm{cm}$ への取り直しは $k = 10^2$ で、長さの数値は $10^2$ 倍になり、面積の数値は $10^4$ 倍になる。

等式の左辺の $\mathsf{L}$ の指数を $a$、右辺の指数を $p$ とする。単位を取り直しても等式が成り立つなら、両辺の数値の倍率が等しいので $k^a = k^p$ である。$k > 1$ では指数が異なると累乗の値も異なることを、本章の事実として認める。よって $a = p$ である。質量の単位と時間の単位についても同じである。

和と差も同じ理由で制限される。$3\ \mathrm{m}$ と $2\ \mathrm{s}$ の和には意味が無い。長さの単位を取り直すと $3$ だけが変わり、和の数値に共通の倍率が付かないからである。

原理の対偶から、両辺の次元が異なる等式は正しくない。式を確かめる例として、一定の速さ $v$ で時間 $t$ の間に進む距離 $x$ の式を考える。

| 式         | 右辺の次元                                                            | 判定                             |
| ---------- | --------------------------------------------------------------------- | -------------------------------- |
| $x = vt$   | $\mathsf{L}\mathsf{T}^{-1} \cdot \mathsf{T} = \mathsf{L}$             | 次元が一致する。式も正しい       |
| $x = vt^2$ | $\mathsf{L}\mathsf{T}^{-1} \cdot \mathsf{T}^2 = \mathsf{L}\mathsf{T}$ | 次元が異なる。式は誤りである     |
| $x = 2vt$  | $\mathsf{L}\mathsf{T}^{-1} \cdot \mathsf{T} = \mathsf{L}$             | 次元は一致するが、式は誤りである |

表の 3 行目が示すとおり、次元の一致は式が正しいための必要条件であり、十分条件ではない。数の係数は無次元なので、次元からは係数の誤りを見つけられない。

振り子を動かす原因は重力、すなわち地球が物体を引く力である。空気の影響を無視できるとき、地表の近くで静かに放した物体の速さは、$1\ \mathrm{s}$ ごとに約 $9.8\ \mathrm{m/s}$ ずつ増える。増える割合は物体の質量に依らない。増える割合を**重力加速度**と呼び、$g$ と書く。斜体の $g$ は量で、立体の単位 $\mathrm{g}$（グラム）とは別である。

記号 $\approx$ は「ほぼ等しい」と読む正式な記号である。

$$
g \approx 9.8\ \mathrm{m/s^2}
$$

$g$ の値と、$g$ が質量に依らないことは、測定で得られる事実として扱う。$g$ は加速度なので、$[g] = \mathsf{L}\mathsf{T}^{-2}$ である。

**手順 1.** 重力の効き方は $g$ を通して表れるとする。周期 $P$ は $m$・$l$・$g$ だけで決まると仮定する。

**手順 2.** 積の形を仮定する。

$$
P = C m^a l^b g^c
$$

**手順 3.** 両辺の次元を比べる。

$$
\mathsf{T} = \mathsf{M}^a\mathsf{L}^b\,(\mathsf{L}\mathsf{T}^{-2})^c = \mathsf{L}^{b+c}\mathsf{M}^a\mathsf{T}^{-2c}
$$

次元の一致により、両辺の $\mathsf{L}$・$\mathsf{M}$・$\mathsf{T}$ の指数はそれぞれ等しい。左辺の $\mathsf{L}$ と $\mathsf{M}$ の指数は $0$ なので、次の連立一次方程式を得る。

$$
\begin{cases}
b + c = 0 & (\mathsf{L} \text{ の指数}) \\
a = 0 & (\mathsf{M} \text{ の指数}) \\
-2c = 1 & (\mathsf{T} \text{ の指数})
\end{cases}
$$

**手順 4.** 連立一次方程式を解く。$\mathsf{T}$ の式から $c = -\dfrac{1}{2}$ である。$c$ を $\mathsf{L}$ の式へ代入すると $b = \dfrac{1}{2}$ である。未知数は 3 つあるが、1 つの文字だけを含む式から順に代入すれば解ける。解はただ 1 組である。

指数を元の式へ戻す。$a = 0$ なので $m^0 = 1$ となり、$m$ は式から消える。残りには、有理数指数の定義 $x^{1/2} = \sqrt{x}$（$x > 0$）と指数法則を使う。

$$
P = C l^{1/2} g^{-1/2} = C\sqrt{\frac{l}{g}}
$$

手順 1・2 の仮定のもとで、次のことが読み取れる。

- 周期はおもりの質量に依らない。
- 周期は糸の長さの平方根に比例する。糸を 4 倍にすると、周期は 2 倍になる。
- $C$ は次元からは決まらない。1 組の測定値があれば $C = P\sqrt{g/l}$ で定まる。

### 解が 1 組に定まらない場合

[一次方程式と連立一次方程式](../../../math/algebra/linear-equations-and-systems/)の未知数 2 つの場合と同じく、指数の連立一次方程式の解も、ただ 1 組とは限らない。解がただ 1 組でない 2 つの場合を、振り子で確かめる。

**解なし.** $g$ を挙げ忘れて $P = C m^a l^b$ と仮定する。$\mathsf{T}$ の指数を比べると $1 = 0$ になり、解が無い。解なしは、決める量の挙げ方が足りないことを示す。

**解が無数.** 振れ幅 $d$ を加えて $P = C m^a l^b g^c d^e$ と仮定する。$d$ の次元は $\mathsf{L}$ である。指数の式は次の 3 つになる。

$$
b + c + e = 0, \qquad a = 0, \qquad -2c = 1
$$

未知数 4 つに対して式が 3 つなので、$e$ を決められない。$c = -\dfrac{1}{2}$、$b = \dfrac{1}{2} - e$ を代入すると、関係は次の形になる。

$$
P = C\sqrt{\frac{l}{g}}\left(\frac{d}{l}\right)^e
$$

$d/l$ は無次元量なので、次元を比べても $d/l$ への依存は分からない。積の形の仮定のもとでは、$P\sqrt{g/l}$ は $d/l$ で決まる。実際の依存は $d/l$ の累乗 1 つとは限らない。前節の結果は、$d/l$ の影響を無視できるほど振れ幅が小さいときに成り立つ。

### 測定値の読み方

測定値には読み取りの限界がある。定規で測った長さの読みが $12.3\ \mathrm{cm}$ であるとする。最後の桁の $3$ は目分量を含む。測定の対象が持つ本当の値を**真の値**と呼ぶ。

> **測定値の読み方（約束）.** 本章では、真の値を四捨五入した値が測定値であると読む。

四捨五入は、切り捨てる部分の最上位の数字が $4$ 以下なら切り捨て、$5$ 以上なら切り上げる操作である。測定値 $12.3$ の真の値は $12.25$ 以上 $12.35$ 未満にある。次の図は範囲を示す。

測定値を表す数字のうち、位取りのためだけの $0$ を除いた数字を**有効数字**と呼ぶ。有効数字の個数を**桁数**と呼ぶ。$12.3$ の有効数字は $1$・$2$・$3$ の 3 桁である。

数え方の規則は次のとおりである。

| 値       | 桁数 | 数え方                                                  |
| -------- | ---- | ------------------------------------------------------- |
| $0.0120$ | 3    | 先頭の $0$ は位取りなので数えない。末尾の $0$ は数える  |
| $10.05$  | 4    | 測定した数字にはさまれた $0$ は数える                   |
| $12.30$  | 4    | 小数点より右にある末尾の $0$ は測定した数字として数える |
| $1200$   | 不明 | 整数の末尾の $0$ は、位取りと測定した数字を区別できない |

### 指数を使う書き方

整数の末尾の $0$ を区別するには、次の形を使う。$a$ は $1$ 以上 $10$ 未満の数、$n$ は整数である。

$$
a \times 10^n
$$

有効数字は $a$ の数字に表れる。$1200$ を 2 桁で示すなら $1.2 \times 10^3$、3 桁で示すなら $1.20 \times 10^3$ と書く。

### 計算の規則

測定値の計算では、結果を四捨五入して、桁を次の 2 つの規則で定める。

- **積と商**: 結果の桁数を、入力の中で最も少ない桁数にそろえる。
- **和と差**: 入力の最後の数字の位を比べ、最も大きい位に結果の最後の位をそろえる。

積の規則を $2.3 \times 1.46 = 3.358$ で確かめる。$2.3$ の真の値は $2.25$ 以上 $2.35$ 未満で、$1.46$ の真の値は $1.455$ 以上 $1.465$ 未満である。正の数では大きい数どうしの積が大きいので、積の真の値は次の範囲にある。

$$
2.25 \times 1.455 \approx 3.27, \qquad 2.35 \times 1.465 \approx 3.44
$$

範囲の幅は約 $0.17$ である。小数第 2 位は定まらない。小数第 1 位も揺れるが、最後の桁が定まらない点は測定値と同じである。結果は少ないほうの桁数 2 桁にそろえ、$3.4$ と書く。

範囲の幅は、$2.3$ では値の約 $0.04$ 倍、$1.46$ では値の約 $0.007$ 倍、積では値の約 $0.05$ 倍である。桁数の少ない入力が、積の幅を決める。

和の規則を $12.3 + 0.456 = 12.756$ で確かめる。和の真の値の範囲の両端は $12.25 + 0.4555 = 12.7055$ と $12.35 + 0.4565 = 12.8065$ である。範囲の幅は約 $0.1$ なので、小数第 2 位以下を書いても意味が無い。結果は大きいほうの位である小数第 1 位にそろえ、$12.8$ と書く。

和の範囲の幅は、入力の幅 $0.1$ と $0.001$ の和である。位の大きい入力が、和の幅を決める。

規則の適用には次の注意がある。

- 数え上げた個数と、定義で決まる値は、桁数の制限に入らない。例えば $1\ \mathrm{km} = 10^3\ \mathrm{m}$ の $10^3$ である。
- 円周率 $\pi$ は、測定値より 1 桁以上多く使う。
- 計算の途中では 1 桁多く残し、最後に四捨五入で桁を減らす。桁を減らす操作を**丸める**と呼ぶ。途中で丸めると、丸めたずれが積み重なる。
- 2 つの規則は桁の目安である。結果を測定値と同じように読んだ範囲は、実際の範囲と厳密には一致しない。

## 例題

### 例題 1

測定した速さが $72\ \mathrm{km/h}$ である。$72$ を有効数字 2 桁として、速さを $\mathrm{m/s}$ で表せ。

**解法.** $\mathrm{km}$ と $\mathrm{h}$ を置き換える。

$$
72\ \mathrm{km/h} = 72 \times \frac{10^3\ \mathrm{m}}{3600\ \mathrm{s}} = 20\ \mathrm{m/s}
$$

$10^3$ と $3600$ は定義で決まる値なので、桁数の制限に入らない。結果は 2 桁で、$2.0 \times 10^1\ \mathrm{m/s}$ と書く。

### 例題 2

体積あたりの質量を**密度**と呼び、$\rho$ と書く。$\rho$ は「ロー」と読むギリシャ文字である。半径 $r$、密度 $\rho$ の球の質量 $m$ の式として、次の 2 つが提案された。次元を比べて、誤りの式を見つけよ。

1. $m = \dfrac{4}{3}\pi r^3 \rho$
2. $m = 4\pi r^2 \rho$

**解法.** 密度の単位は $\mathrm{kg/m^3}$ なので、$[\rho] = \mathsf{L}^{-3}\mathsf{M}$ である。$\dfrac{4}{3}\pi$ と $4\pi$ は無次元である。右辺の次元を求める。

$$
\text{式 1}\quad \mathsf{L}^3 \cdot \mathsf{L}^{-3}\mathsf{M} = \mathsf{M}, \qquad
\text{式 2}\quad \mathsf{L}^2 \cdot \mathsf{L}^{-3}\mathsf{M} = \mathsf{L}^{-1}\mathsf{M}
$$

左辺の次元は $\mathsf{M}$ である。式 2 の次元は一致しないので、式 2 は誤りである。式 1 は次元が一致する。ただし、次元の一致は十分条件ではない。式 1 の正しさは、球の体積の公式 $\dfrac{4}{3}\pi r^3$ に密度を掛けた形であることから確かめる。

### 例題 3

高さ $h$ から静かに放した物体が地面に届くときの速さ $v$ を考える。空気の影響を無視し、$v$ は物体の質量 $m$、$g$、$h$ だけで決まると仮定する。次元解析で $v$ の形を求めよ。さらに、$h$ を 4 倍にすると $v$ は何倍になるかを求めよ。

**解法.** 積の形 $v = C m^a g^b h^c$ を仮定する。$C$ は無次元の定数である。両辺の次元を比べる。

$$
\mathsf{L}\mathsf{T}^{-1} = \mathsf{M}^a\,(\mathsf{L}\mathsf{T}^{-2})^b\mathsf{L}^c = \mathsf{L}^{b+c}\mathsf{M}^a\mathsf{T}^{-2b}
$$

指数を比べる。

$$
\begin{cases}
b + c = 1 & (\mathsf{L} \text{ の指数}) \\
a = 0 & (\mathsf{M} \text{ の指数}) \\
-2b = -1 & (\mathsf{T} \text{ の指数})
\end{cases}
$$

$\mathsf{M}$ の式から $a = 0$ なので、$m$ は式から消える。$\mathsf{T}$ の式から $b = \dfrac{1}{2}$ である。$\mathsf{L}$ の式へ代入すると $c = \dfrac{1}{2}$ である。

$$
v = C g^{1/2} h^{1/2} = C\sqrt{gh}
$$

$v$ は $h$ の平方根に比例するので、$h$ を 4 倍にすると $v$ は 2 倍になる。

### 例題 4

長方形の板の測定値は、縦 $2.37\ \mathrm{m}$、横 $1.2\ \mathrm{m}$ である。面積と周の長さを、有効数字の規則に従って求めよ。

**解法.** 面積は積である。入力の少ないほうの桁数は 2 桁である。

$$
2.37 \times 1.2 = 2.844
$$

面積は 2 桁にそろえて $2.8\ \mathrm{m^2}$ である。

周の長さは和である。途中では 1 桁多く残して計算する。$2$ は数え上げた個数なので、桁数の制限に入らない。

$$
2 \times (2.37 + 1.2) = 2 \times 3.57 = 7.14
$$

大きいほうの最後の位は小数第 1 位である。周の長さは $7.1\ \mathrm{m}$ である。途中の $3.57$ を $3.6$ に丸めると $7.2$ になり、結果がずれる。

### 問題 4

密度 $\rho$ と速さ $v$ の 2 乗の積 $\rho v^2$ の次元が、圧力 $p$ の次元に等しいことを示せ。

<details>
<summary>解答を表示</summary>

圧力の単位は $\mathrm{kg\,m^{-1}\,s^{-2}}$ なので、$[p] = \mathsf{L}^{-1}\mathsf{M}\mathsf{T}^{-2}$ である。$\rho v^2$ の次元は次のとおりである。

$$
[\rho v^2] = [\rho][v]^2 = \mathsf{L}^{-3}\mathsf{M} \cdot (\mathsf{L}\mathsf{T}^{-1})^2 = \mathsf{L}^{-1}\mathsf{M}\mathsf{T}^{-2}
$$

2 つの次元は等しい。

</details>

### 問題 5

$x$ は距離、$v$ は速さ、$a$ は加速度、$t$ は時間である。次の式のうち、次元が一致しないものを選べ。

1. $x = vt + at$
2. $v^2 = ax$
3. $t = \sqrt{\dfrac{x}{a}}$

<details>
<summary>解答を表示</summary>

1. $[vt] = \mathsf{L}$、$[at] = \mathsf{L}\mathsf{T}^{-1}$ である。和の各項の次元が異なるので、式 1 の次元は一致しない。
2. 左辺は $[v^2] = \mathsf{L}^2\mathsf{T}^{-2}$ である。右辺は $[ax] = \mathsf{L}\mathsf{T}^{-2} \cdot \mathsf{L} = \mathsf{L}^2\mathsf{T}^{-2}$ である。次元は一致する。
3. $[x/a] = \mathsf{L}/(\mathsf{L}\mathsf{T}^{-2}) = \mathsf{T}^2$ なので、右辺の次元は $\mathsf{T}$ である。次元は一致する。

次元が一致しない式は 1 だけである。

</details>

### 問題 6

波の隣り合う山の間の距離を**波長**と呼び、$\lambda$ と書く。$\lambda$ は「ラムダ」と読むギリシャ文字である。深い水の表面を進む波の速さ $v$ は、$\lambda$ と $g$ だけで決まると仮定する。次元解析で $v$ の形を求めよ。

<details>
<summary>解答を表示</summary>

$v = C \lambda^a g^b$ を仮定する。$C$ は無次元の定数である。

$$
\mathsf{L}\mathsf{T}^{-1} = \mathsf{L}^a\,(\mathsf{L}\mathsf{T}^{-2})^b = \mathsf{L}^{a+b}\mathsf{T}^{-2b}
$$

指数を比べると $a + b = 1$、$-2b = -1$ である。$b = \dfrac{1}{2}$、$a = \dfrac{1}{2}$ を得る。

$$
v = C\sqrt{g\lambda}
$$

</details>

### 問題 7

質量 $m$、速さ $v$ の物体のエネルギー $E$ が、$m$ と $v$ だけで決まると仮定する。積の形 $E = C m^a v^b$ から $a$ と $b$ を求めよ。

<details>
<summary>解答を表示</summary>

エネルギーの単位は $\mathrm{kg\,m^2\,s^{-2}}$ なので、$[E] = \mathsf{L}^2\mathsf{M}\mathsf{T}^{-2}$ である。

$$
\mathsf{L}^2\mathsf{M}\mathsf{T}^{-2} = \mathsf{M}^a\,(\mathsf{L}\mathsf{T}^{-1})^b = \mathsf{L}^b\mathsf{M}^a\mathsf{T}^{-b}
$$

指数を比べると、$b = 2$、$a = 1$、$-b = -2$ である。式は 3 つあるが、3 つとも $a = 1$、$b = 2$ で成り立つ。

$$
E = C m v^2
$$

</details>

### 問題 8

流体（液体や気体）の中を動く球が流体から受ける力 $F$ が、流体の密度 $\rho$、球の速さ $v$、球の半径 $r$ だけで決まると仮定する。積の形 $F = C \rho^a v^b r^c$ から $a$・$b$・$c$ を求めよ。

<details>
<summary>解答を表示</summary>

両辺の次元を比べる。

$$
\mathsf{L}\mathsf{M}\mathsf{T}^{-2} = (\mathsf{L}^{-3}\mathsf{M})^a\,(\mathsf{L}\mathsf{T}^{-1})^b\mathsf{L}^c = \mathsf{L}^{-3a+b+c}\mathsf{M}^a\mathsf{T}^{-b}
$$

指数を比べる。

$$
\begin{cases}
-3a + b + c = 1 & (\mathsf{L} \text{ の指数}) \\
a = 1 & (\mathsf{M} \text{ の指数}) \\
-b = -2 & (\mathsf{T} \text{ の指数})
\end{cases}
$$

$a = 1$、$b = 2$ を $\mathsf{L}$ の式へ代入すると $c = 2$ である。

$$
F = C \rho v^2 r^2
$$

</details>

### 問題 9

例題 3 と同じく $m$ の指数は $0$ なので、$m$ を省く。物体の大きさ $d$（次元は $\mathsf{L}$）を加え、$v = C g^b h^c d^e$ と仮定する。指数の連立一次方程式の解が無数にあることを示し、$v$ の形を書け。

<details>
<summary>解答を表示</summary>

両辺の次元を比べる。

$$
\mathsf{L}\mathsf{T}^{-1} = (\mathsf{L}\mathsf{T}^{-2})^b\mathsf{L}^c\mathsf{L}^e = \mathsf{L}^{b+c+e}\mathsf{T}^{-2b}
$$

指数を比べると $b + c + e = 1$、$-2b = -1$ である。未知数 3 つに対して式が 2 つなので、$b = \dfrac{1}{2}$、$c = \dfrac{1}{2} - e$ となり、$e$ を決められない。

$$
v = C g^{1/2} h^{1/2-e} d^e = C\sqrt{gh}\left(\frac{d}{h}\right)^e
$$

$d/h$ は無次元量なので、次元からは $d/h$ への依存が分からない。積の形の仮定のもとでは、$v/\sqrt{gh}$ は $d/h$ で決まる。

</details>

### 問題 10

次の測定値の有効数字の桁数を答えよ。

1. $0.00450$
2. $6.02 \times 10^{23}$
3. $10.0$
4. $3.0 \times 10^{-2}$

<details>
<summary>解答を表示</summary>

1. 先頭の $0$ は数えない。$4$・$5$・$0$ の 3 桁である。
2. $a$ の数字 $6$・$0$・$2$ の 3 桁である。
3. 数字にはさまれた $0$ と、小数点より右の末尾の $0$ を数える。$1$・$0$・$0$ の 3 桁である。
4. $a$ の数字 $3$・$0$ の 2 桁である。

</details>

### 問題 11

次の測定値の計算を、有効数字の規則に従って行え。

1. $3.2 \times 4.56$
2. $12.34 + 5.6$
3. $5.63 - 5.58$
4. 半径 $2.50\ \mathrm{cm}$ の円の面積

<details>
<summary>解答を表示</summary>

1. $3.2 \times 4.56 = 14.592$ である。少ないほうの桁数は 2 桁なので、結果は $15$ である。
2. $12.34 + 5.6 = 17.94$ である。大きいほうの最後の位は小数第 1 位なので、結果は $17.9$ である。
3. $5.63 - 5.58 = 0.05$ である。最後の位はどちらも小数第 2 位である。結果の有効数字は 1 桁に減る。近い値の差では桁数が減る。
4. $\pi$ を 4 桁の $3.142$ として計算する。$3.142 \times 2.50^2 = 19.6375$ である。半径の 3 桁にそろえて、面積は $19.6\ \mathrm{cm^2}$ である。

</details>

## まとめ

本章は、物理量の書き方と式の確かめ方を扱った。要点を振り返る。

- 物理量は数値と単位の積である。単位を変えても物理量は変わらない。
- SI は 7 つの基本単位を定める。組立単位は、基本単位の積と商に係数 $1$ で結び付く。
- 接頭語は $10$ の累乗を表す。累乗は接頭語ごとかかる。
- 次元は、量の基本量への依存の仕方を、単位の選び方と無関係に表す。物理量を結ぶ正しい等式の両辺の次元は等しい。次元の一致は式が正しいための必要条件である。
- 次元解析は積の形を仮定し、指数の連立一次方程式を解いて量の関係の形を求める。無次元の係数と、無次元の組み合わせへの依存は決まらない。
- 有効数字の計算では、積と商は桁数を、和と差は最後の位をそろえる。
