# 学習ロードマップ設計書

本書は物理学ロードマップの全体設計を定める。章執筆の唯一の正とする。章は本書の依存順に従って書く。

## ベースラインとゴール

- ベースライン: 本ロードマップが前提とする知識。特定の学年や課程に依らず、カテゴリ「前提とする知識」（PRE-01）で算数・数学・理科の前提を具体的に明記する。
- ゴール: 次の2つを数式として理解する。
  - 標準模型のラグランジアン。各項の意味と導出の筋を追える水準に至る。
  - 一般相対性理論。アインシュタイン方程式を読み、シュワルツシルト解・重力波・宇宙論の初歩まで追える水準に至る。

## 設計原則

### 自己完結

- 一連の章のみでゴールへ到達できる構成とする。
- 説明の論理を外部資料に委ねない。「詳細は専門書を参照」と書かない。
- 前提とする知識に含まれない数学（微積分・三角関数・ベクトルなど）も、使う前に章内で導入する。
- 完全な厳密証明が過大になる箇所は、直観と結果の承認で扱い、射程外であると明示する。
- 実験で決まる量（結合定数・粒子の質量など）は導出しない。所与の入力値として提示し、理論の論理を途切れさせない。

### 演習による習得

- 到達水準は「演習で身に付く」とする。読んで終わりにしない。
- 各章に例題と演習問題を置く。演習には解答を付ける。

### 参考文献と脚注

- さらに学ぶための一次資料・データ出典は、章末の「参考文献」の節に箇条書きでまとめる。
- 参考文献は信頼できる一次資料に限る。原論文・標準的な教科書・公的機関のデータなどを対象とする。
- 脚注は本来の補足説明に充てる。論理の鎖の一部にはしない。脚注を読まなくても本文だけで理解できる構成を保つ。

## モジュール体系

- モジュールは35カテゴリに分ける。各カテゴリは単一の分野とする。前提トラックは1、数学トラックは22、物理トラックは12である。
- ID は「トラック接頭辞-分野コード-連番」で表す。数学トラックは M、物理トラックは P を接頭辞に付ける（例: M-LIN-04、P-QM-03）。ID は本書の中だけで使い、読者向けの本文に出さない。
- 各モジュールは 1 つの主題を持ち、1 章に対応する。
- 前提の列は ID で記す。直接の上流だけを書き、推移的に得られる ID を重ねない。
- 総モジュール数は358とする。

### 表の読み方

- 行の順序が読む順序である。カテゴリの中では、上にある行だけを前提にする。
- 「扱う内容」は章に載せる話題の全部である。行に無い話題を章に載せるときは、先に行を変える。
- 「章」の列は、行の内容を載せる章のファイルである。`src/content/docs/`からの相対パスで書く。未執筆の行は`—`とする。
  - 分割を待つ章は、複数の行に同じファイルを書く。
  - 統合を待つ章は、1 行に 2 つのファイルを書く。
- 任意枠の行は、ゴールの経路の外にある物理の基礎である。本線の行は任意枠の行を前提にしない。
- `pnpm run roadmap:check`が、前提の ID、循環、本線と任意枠の関係、章のファイル、切れたリンク、上流以外へのリンクを検査する。

### 章の粒度

分割と統合は、字数でなく内容で判断する。

**分割する条件.** 次の 2 つをともに満たす。

1. 主題が 2 つある。主定理か独立した定義の体系が 2 つ以上あり、片方が他方の系・例・言い換えでない。
2. 境界で前半が閉じ、両側に例題と演習を置ける。

**統合する条件.** 次の 2 つをともに満たす。

1. 片方に主定理が無い（定義・適用・系・例だけである）か、内容が重複する。
2. 統合しても主題が 1 つである。

下流の章がどちら側を引用しているかを傍証にする。片側だけを引く章が多ければ、主題は独立している。

### 符号と単位の規約

物理トラックの符号と単位は、次の規約に従う。

#### 計量の符号

分野の標準に合わせて、2 つの符号を使い分ける。読者がゴールで出会う式の形を優先するためである。

| 範囲                                                         | 計量        | 代表的な式                                                                            |
| ------------------------------------------------------------ | ----------- | ------------------------------------------------------------------------------------- |
| 特殊相対論、電磁気学の P-EM-15、リーマン幾何、一般相対性理論 | $(-,+,+,+)$ | $u^\mu u_\mu=-c^2$、$g_{00}\approx-(1+2\Phi/c^2)$                                     |
| 相対論的量子力学、場の量子論、ゲージ理論、標準模型           | $(+,-,-,-)$ | $p^2=m^2$、$(\Box+m^2)\phi=0$、$\mathcal{L}=\frac12(\partial\phi)^2-\frac12m^2\phi^2$ |

切り替えは P-RQM-01 で 1 回だけ明示する。P-EM-15 は切り替えの前にあるので、$(-,+,+,+)$ で書く。P-QFT-10 は P-EM-15 の結果を $(+,-,-,-)$ で書き直す。

#### 電荷

| 項目              | 規約                                                                                                                           |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| 記号              | $e>0$ は電気素量である。粒子の電荷を $q=Qe$ と書く。電子は $Q=-1$ である                                                       |
| 最小結合          | $\vec p\to\vec p-q\vec A$、$E\to E-q\phi$。共変形は計量によらず $p_\mu\to p_\mu-qA_\mu$ である                                 |
| 波動関数の位相    | ゲージ変換 $\vec A\to\vec A+\nabla\chi$、$\phi\to\phi-\partial\chi/\partial t$ に対して $\psi\to e^{iq\chi/\hbar}\psi$ である  |
| $U(1)$ の共変微分 | $(+,-,-,-)$ で $D_\mu=\partial_\mu+iqA_\mu$ である                                                                             |
| QED の相互作用    | $\mathcal{L}_{\rm int}=-q\bar\psi\gamma^\mu\psi A_\mu$                                                                         |
| 非可換の共変微分  | $D_\mu=\partial_\mu+igA_\mu^aT^a$、$[T^a,T^b]=if^{abc}T^c$                                                                     |
| 非可換の場の強さ  | $F_{\mu\nu}^a=\partial_\mu A_\nu^a-\partial_\nu A_\mu^a-gf^{abc}A_\mu^bA_\nu^c$                                                |
| 電弱の共変微分    | $D_\mu=\partial_\mu+igW_\mu^aT^a+ig'\frac{Y}{2}B_\mu$                                                                          |
| 電弱の場の混合    | $A_\mu=\sin\theta_WW_\mu^3+\cos\theta_WB_\mu$、$Z_\mu=\cos\theta_WW_\mu^3-\sin\theta_WB_\mu$、$e=g\sin\theta_W=g'\cos\theta_W$ |
| 電弱の光子の項    | $D_\mu\supset ieQA_\mu$。$U(1)$ の共変微分 $\partial_\mu+iqA_\mu$ と一致する                                                   |

$D_\mu=\partial_\mu-igA_\mu^aT^a$ と書く文献は多い。共変微分と場の強さの式は、$g\to-g$、$g'\to-g'$ で本書の式へ移る。

#### 単位

| 範囲                                               | 単位                                                                                       |
| -------------------------------------------------- | ------------------------------------------------------------------------------------------ |
| 古典力学から量子力学まで、統計力学                 | SI 単位。$\hbar$ と $c$ を明示する                                                         |
| 相対論的量子力学、場の量子論、ゲージ理論、標準模型 | 自然単位系 $\hbar=c=1$。P-RQM-01 で導入する                                                |
| P-QFT-10 より後の電磁場                            | ヘビサイド-ローレンツ単位 $\varepsilon_0=\mu_0=1$。微細構造定数は $\alpha=e^2/4\pi$ である |
| 一般相対性理論                                     | $c$ と $G$ を明示する                                                                      |

自然単位系から戻すには、質量・エネルギー・運動量・長さの逆数・時間の逆数が同じ次元になることを使う。換算には $\hbar c\approx197.3\ \mathrm{MeV\,fm}$ を使う。SI 単位の微細構造定数は $\alpha=e^2/(4\pi\varepsilon_0\hbar c)\approx1/137$ である。

#### 換算

2 つの計量の間の換算を次に示す。物理量はどちらも同じである。

| 量                        | $(-,+,+,+)$                                | $(+,-,-,-)$                               |
| ------------------------- | ------------------------------------------ | ----------------------------------------- |
| 内積                      | $a^\mu b_\mu=-a^0b^0+\vec a\cdot\vec b$    | $a^\mu b_\mu=a^0b^0-\vec a\cdot\vec b$    |
| 4 元速度の規格化          | $u^\mu u_\mu=-c^2$                         | $u^\mu u_\mu=c^2$                         |
| エネルギー運動量の関係    | $p^\mu p_\mu=-m^2c^2$                      | $p^\mu p_\mu=m^2c^2$                      |
| ダランベール演算子        | $\Box=-\frac{1}{c^2}\partial_t^2+\nabla^2$ | $\Box=\frac{1}{c^2}\partial_t^2-\nabla^2$ |
| クライン-ゴルドン方程式   | $(\Box-m^2c^2/\hbar^2)\phi=0$              | $(\Box+m^2c^2/\hbar^2)\phi=0$             |
| 運動量の演算子            | $p_\mu=-i\hbar\partial_\mu$                | $p_\mu=i\hbar\partial_\mu$                |
| 下付きの 4 元ポテンシャル | $A_\mu=(-\phi/c,\vec A)$                   | $A_\mu=(\phi/c,-\vec A)$                  |
| 上付きのゲージ変換        | $A^\mu\to A^\mu+\partial^\mu\chi$          | $A^\mu\to A^\mu-\partial^\mu\chi$         |
| 場テンソルの電場の成分    | $F^{0i}=E^i/c$                             | $F^{0i}=-E^i/c$                           |
| 場テンソルの磁場の成分    | $F^{ij}=\epsilon_{ijk}B^k$                 | $F^{ij}=-\epsilon_{ijk}B^k$               |
| マクスウェル方程式        | $\partial_\mu F^{\nu\mu}=\mu_0J^\nu$       | $\partial_\mu F^{\mu\nu}=\mu_0J^\nu$      |
| 粒子の作用                | $S=-mc^2\int d\tau+q\int A_\mu dx^\mu$     | $S=-mc^2\int d\tau-q\int A_\mu dx^\mu$    |

どちらの計量でも $A^\mu=(\phi/c,\vec A)$、$J^\mu=(c\rho,\vec J)$、$F^{\mu\nu}=\partial^\mu A^\nu-\partial^\nu A^\mu$、$F_{\mu\nu}F^{\mu\nu}$、ローレンツ力 $m\,du^\mu/d\tau=qF^{\mu\nu}u_\nu$ の形は同じである。

#### 換算の扱い

- 章は 2 つの計量の式を並べて書かない。例外は切り替えを説明する P-RQM-01 である。
- 換算表は、相対論的量子力学と一般相対性理論の付録に置く。

### 線形代数（M-LIN）

執筆の前に決めた規約を、次に定める。

- **係数.** M-LIN-01 で「係数 $K$ は $\mathbb{R}$ または $\mathbb{C}$」と定める。体の語は使わない。M-LIN-12 が実行列の複素固有値を扱うので、複素数の係数を最初から入れる。
- **ベクトルの記法.** 公開済みの章と同じ $\vec{a}$ を使う。成分を横に書く $(a_1,\dots,a_n)$ と列ベクトルの同一視を、M-LIN-04 で明記する。

- **次元.** 有限次元に限る。関数の空間は例として出すが、次元を論じない。

### 読む順の注意

**数学の順序との差.** 数学のカテゴリの順は、線形代数 → 常微分方程式 → 変分法 → フーリエ解析 → 偏微分方程式 → 特殊関数 → 確率 → 複素解析 → 抽象代数 → 表現論 → リー群とリー代数 → リーマン幾何である。差は 1 点である。

- 段階の表は、M-PDE-01・M-PDE-03 だけを M-FOU より先に読む（G3）。電磁気学が M-FOU を使わないからである。
- M-PDE-02・04・05・06 は、G4 で M-FOU と一緒に読む。M-PDE-04〜06 が M-FOU を使う。
- M-PDE-01・M-PDE-03 は M-FOU に依存しないので、この読み方は前提に反しない。

- 特殊相対論は線形代数の全行を要しない。P-SR-03 の閉包に入る線形代数は 15 行で、M-LIN-11〜11・15・16 を通らない。

## クリティカルパス

ゴールは 2 つある。標準模型（P-SMD-10）と一般相対性理論（P-GR-16 ほか）である。共通の基盤は数学トラックの前半に置く。

経路は手書きしない。ゴールの行が推移的に必要とする行の全体（閉包）は、前提の列から`pnpm run roadmap:paths -- <ID>`で求める。推移的な依存の数は、本節の「ゴールまでの距離」の表に書く。

### 標準模型への経路

閉包には数学の前半のすべてと、線形代数・常微分方程式・変分法・フーリエ解析・偏微分方程式・特殊関数・確率・複素解析・抽象代数・表現論・リー群とリー代数が入る。物理は古典力学・解析力学・特殊相対論・電磁気学・量子力学・相対論的量子力学・場の量子論・ゲージ理論を通る。熱力学と統計力学は入らない。

標準模型のラグランジアンでは、3 本の柱が合流する。

1. ゲージ原理: 電磁場のゲージ変換 → 電磁場の量子化 → 非可換ゲージ理論 → 電弱相互作用と強い相互作用
2. 物質場: ディラック方程式 → ディラック場の量子化 → クォークとレプトンの割り当て → 湯川項
3. 対称性の破れ: 自発的対称性の破れ → ヒッグス機構 → ヒッグス場

### 一般相対性理論への経路

閉包には数学の前半と、線形代数・リーマン幾何が入る。物理は古典力学・特殊相対論を通る。一般相対性理論は量子論を要しない。抽象代数・表現論・電磁気学も閉包に入らない。標準模型から独立した枝である。

## 章テンプレート

各章は次の構成とする。

1. frontmatter: `title`は必須、`description`は任意とする。
2. 前提: 本書の前提の列にある直接の上流の章へのリンクを置く。
3. 学習目標: 章で読めるようになる数式・概念を箇条書きで示す。
4. 本文: 導入から展開へ進める。表現手段は次のとおり使い分ける。
   - 数式: KaTeX（インライン`$...$`、ブロック`$$ ... $$`）。
   - 概念図・フロー: `FlowChart`コンポーネント（`@dagrejs/dagre` ＋ `@visx/network`）。ビルド時に静的 SVG を生成する。
   - 2D 数学・幾何（関数・幾何・ベクトル・ベン図・数直線）: ビルド時に静的 SVG を生成する React コンポーネント（`FunctionGraph`・`VennDiagram`・`SpaceVectorDiagram`など）。標準ライブラリは visx（`@visx/*`）とし、`client:only`は付けない。
   - データグラフ: visx によるビルド時の静的 SVG を標準とする。高水準の図が要るときは`@visx/xychart`を導入する。データ図が必要な章で導入する。
   - 3D（曲面・3D ベクトル場・時空）: 物理段階で react-three-fiber を導入する。数学段階の空間ベクトルは`SpaceVectorDiagram`の静的 SVG で表す。
   - 表現手段の選定方針は[可視化スタック設計](superpowers/specs/2026-06-24-visualization-stack-design.md)に従う。
5. 例題: 解法を示す。
6. 演習問題: 解答を付ける。
7. まとめ: 章内で要点を振り返って閉じる。下流の章へのリンクを置かない。
8. 参考文献: 一次資料・データ出典を箇条書きで示す。
9. 脚注: 補足説明を示す。
